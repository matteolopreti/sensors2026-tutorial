# One loop, five versions: IEEE SENSORS 2026 tutorial materials

Materials for the tutorial "From Naïve Loops to FAIR Datasheets" (IEEE SENSORS 2026, 25 October 2026).

- `demo/`: a simulated soft sensor, one indentation staircase, and one acquisition loop in five versions (V0–V4). See `demo/README.md`.
- `demo/out/freeze/NUMBERS.md`: the full-length numbers quoted in the slides (generated by `demo/freeze_numbers.py`).
- `kit/demo_colab.ipynb`: the same demo as a Colab notebook (generated by `kit/build_notebook.py` from `demo/*.py`).
- `kit/handout/handout.pdf`: one-page handout. `kit/READING_LIST.md`: sources.

Run locally: `cd demo && uv run --with numpy --with matplotlib python naive_vs_threaded.py --fast --seed 2`.
Tests: `cd demo && uv run --with numpy --with matplotlib --with pytest python -m pytest -q test_demo.py`.

The numbers are from a simulation with an assumed disk-stall model. They change with your machine, OS timer and start phase.
